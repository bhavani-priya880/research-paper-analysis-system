# Data Directory

This directory stores datasets and research paper PDFs used by the system.

## Files & Folders
- `sample_arxiv_metadata.csv`: Curated representative metadata conforming to the schema of `sumitm004/arxiv-scientific-research-papers-dataset` (id, title, summary, summary_word_count, category, category_code, published_date, updated_date, authors, first_author).
- `sample_papers/`: Pre-packaged multi-domain academic research paper PDFs across Computer Science, Mathematics, Physics, Statistics, Quantitative Biology, and Electrical Engineering for instant local testing.
- `arXiv_scientific_dataset.csv`: Optional full dataset file when downloaded locally from Kaggle.
